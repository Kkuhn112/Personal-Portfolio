PROJECT 01 · ROBOTICS · CONTROLS

PAROL 6 Robotic Arm

A six-degree-of-freedom desktop industrial arm — kitted, assembled, calibrated, commissioned, and driven by software I wrote. Built as a platform for controls, calibration, and end-effector experiments.

Robotics Controls Kinematics Python Pneumatics

Overview

Assembled a full six-axis manipulator from a kit — printed structures, stepper drives, belts, wiring, and control electronics — then integrated the software stack to command it.

Design & Build

  • Managed printed-part tolerances, belt alignment, and joint access for serviceability
  • Wired motors, drivers, and limit references into a coherent control loop
  • Integrated a custom end-effector and a pneumatic actuation system

Software

  • Python application for forward and inverse kinematics
  • Cartesian motion control for coordinated multi-axis moves
  • Serial command interface to the motion controller

Result & Next

A functional platform validated through live motion tests. Next steps: closed-loop calibration, repeatability characterization, and task-level end-effector routines.

PROJECT 02 · AUTOMATION · MACHINE DESIGN

Automated CNC Part Extraction System

A custom attachment for a CNC turning center that removes finished parts automatically — designed, manufactured, and deployed on a live production floor at Omni-X to take the operator out of the cycle.

Automation Machine Design CAD Additive Mfg.

Requirement

Reduce machine idle time and manual handling between cycles on a turning center without disrupting the existing workflow or work envelope.

Design

  • Modeled the extraction mechanism in CAD around the machine's envelope
  • Selected chemical-resistant carbon-fiber material for coolant durability
  • Fabricated production-ready hardware with additive manufacturing

Result

  • Eliminated manual operator intervention on the cycle
  • Reduced idle time and improved production consistency
  • Ran on a real production line, not a bench prototype

Lessons

Designing for a live machine forces hard constraints — envelope, repeatability, and coolant exposure drove every geometry and material decision.

PROJECT 03 · RESEARCH · COMPOSITES

Continuous Fiber 3D-Printing Toolpath System

A software pipeline that slices parts for continuous carbon-fiber printing and steers fiber direction through the geometry — the core tool for an undergraduate study on controlling crack propagation in composite prints.

Composites Research Python G-code Mechanical Testing

Objective

Improve strength and crack resistance in printed composite specimens by controlling how continuous fiber is routed relative to expected loading.

Approach

  • Built a slicing and post-processing system producing machine-ready G-code
  • Encoded fiber-steering logic to direct load paths within specimens
  • Handled nozzle-motion continuity and printability constraints

Testing

  • Produced repeatable specimens for comparative mechanical testing
  • Evaluated crack-propagation behavior across fiber strategies

Status

Active research at CU Denver — refining fiber-path generation and expanding the specimen test matrix.

PROJECT 04 · EMBEDDED · DESIGN FOR MANUFACTURING

Custom Computer Macro Pad

A compact, durable input device for repeatable shortcuts — designed around switch spacing, USB access, and print constraints, then built and put to daily use. A tidy demonstration of CAD-to-print electronics packaging.

Embedded DFM CAD FDM Printing

Requirement

A small, sturdy shortcut device that fits the desk, survives daily use, and is fully self-manufactured.

Design for Print

  • Enclosure built around switch spacing and top-plate fit
  • Wall thickness, USB access, and assembly clearances tuned for FDM
  • Print orientation chosen for strength and finish

Build

  • Printed, assembled, and wired mechanical switches
  • Flashed firmware to map keys to shortcuts

Result

A working macro pad in everyday use — proof that a model on screen becomes a reliable physical product when it's designed to be made.

PROJECT 05 · PRECISION · TOOLING

Custom Slitting Saw Arbor

A purpose-built arbor engineered for stiffness and concentricity, so slitting operations on precision parts run stable and repeatable — a machining-first design driven by real tolerances.

Manufacturing Precision Design Turning / Milling Tolerancing

Requirement

Increase rigidity and reliability for slitting precision parts, where deflection and runout show up directly in the cut.

Design

  • Geometry optimized for stiffness, tool access, and machinability
  • Spindle-compatible interface with concentricity as a priority
  • Tolerances chosen to be genuinely producible

Result

A manufacturable arbor that improved stability and confidence during cutting operations.
