# Project Image Folders

Each project has its own folder for screenshots, renders, diagrams, and cover art.

## Cover image convention

- To set a project card cover, add an image named `title` to that project's folder.
- Common browser image types are supported: `title.avif`, `title.webp`, `title.png`, `title.jpg`, `title.jpeg`, `title.gif`, or `title.svg`.
- If a folder has extra photos but none named `title`, the card ignores those extra files and keeps the original fallback artwork/style.
- Additional images can use descriptive names such as `assembly-detail.jpg`, `cad-render.png`, or `testing-setup.webp`.
