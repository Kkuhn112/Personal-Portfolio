# Project Image Folders

Each project has its own folder for screenshots, renders, diagrams, and cover art.

## Cover image convention

- Put the main cover image for a project in that project's folder.
- Name the cover image `cover.svg`; the project cards already point to this file in each project folder and fall back to the CSS cover style until it exists.
- Additional images can use descriptive names such as `assembly-detail.jpg`, `cad-render.png`, or `testing-setup.webp`.
